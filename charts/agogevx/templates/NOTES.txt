1. Watch the stack come up (db -> api -> pgbouncer/report -> frontend):

     kubectl -n {{ .Release.Namespace }} get pods -w

   On first install the frontend may restart a few times until the api writes
   the bootstrap TLS cert to the shared tls-certs volume — this is expected.

2. Confirm the api is healthy:

     kubectl -n {{ .Release.Namespace }} port-forward deploy/api 5000:5000
     curl -k http://localhost:5000/health/ready      # expect database: ok

Scaling the matcher (the primary throughput knob):

     helm upgrade {{ .Release.Name }} . -n {{ .Release.Namespace }} \
       --reuse-values --set matcher.replicas=4

Tearing it down (vxctl keeps your data unless you opt in):

     vxctl teardown --namespace {{ .Release.Namespace }} --yes                    # helm uninstall, PVCs kept
     vxctl teardown --namespace {{ .Release.Namespace }} --yes --delete-namespace # also deletes data
